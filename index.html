❓ Aide

🖱️ Sur ordinateur

  • Clic gauche / glisser : sélectionner (Maj = ajouter)
  • Clic droit : déplacer, récolter, attaquer, construire
  • F + clic : attaque-déplacement · Échap : annuler · X : arrêter
  • R : pivoter un bâtiment · H : hôtel de ville · « . » : villageois inactif
  • Ctrl+1..9 : créer un groupe · 1..9 : le sélectionner (2× = centrer)
  • WASD/ZQSD, flèches ou bords : caméra · molette : zoom

📱 Sur mobile

  • Toucher : sélectionner, puis toucher le sol / une ressource / un ennemi pour donner l'ordre
  • Appui long : sélectionner sans donner d'ordre
  • 1 doigt : déplacer la vue · 2 doigts : zoom
  • Minicarte : toucher pour déplacer la vue

🎯 But

  • Détruisez l'hôtel de ville ennemi, ou faites tenir une Merveille 5 minutes (âge impérial).
  • 💤 Inactifs : nombre de villageois sans tâche ; touchez le bouton pour les retrouver.

⚔ RTS Médiéval

Détruisez l'hôtel de ville ennemi (rouge). Choisissez la difficulté :

Facile : vagues petites et tardives (~8 min) · Normal : 1re vague vers 5:30 · Difficile : IA plus rapide, qui reçoit un bonus de ressources
