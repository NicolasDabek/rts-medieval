# RTS Médiéval (prototype)
RTS 3D dans le navigateur avec Three.js (vendored dans `vendor/`, aucun CDN).
Lancer : `python3 -m http.server` puis ouvrir http://localhost:8000.

Contrôles : clic gauche / glisser = sélection (Maj pour ajouter) · clic droit = déplacer / récolter / déposer · WASD, ZQSD, flèches ou bords de l'écran = caméra · molette = zoom · Échap = annuler le placement.
Hôtel de ville : former un villageois (50 or). Villageois : construire une maison (60 bois, +5 population).
